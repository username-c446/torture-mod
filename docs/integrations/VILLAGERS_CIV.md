# Совместимость с Villagers Civ

Villagers Civ: соседний мод того же автора, `C:\Users\User\Downloads\villagers-civ`, mod id `villagers_civ`.
Рабство там пока описано только в `docs/DESIGN.md` (раздел «Рабство»): источники — пленные и договорные квоты, рабы работают хуже, убегают, бунтуют, есть рынок, выкуп и освобождение.

Документ является предложением контракта. Окончательные имена и сигнатуры выбирает Villagers Civ в своём модуле `api`.

## Принятые решения

- Нужны все четыре связи: пленный житель становится рабом, рабы содержатся в нашей тюрьме, поселение реагирует на плен и пытки, поселения владеют тюрьмами.
- Код совместимости лежит у нас: необязательный модуль `integration-villagersciv`, который зависит только от `api` Villagers Civ.
- Villagers Civ от нас не зависит. Зависимость односторонняя, как у интеграций с Towny.
- Модуль включается, только если Villagers Civ установлен. Без него оба мода работают как обычно.

## Связи

### 1. Пленный житель становится рабом

- Когда в нашем моде ломается житель, который является гражданином поселения, адаптер передаёт его в рабство Villagers Civ владельцу тюрьмы.
- Дальше он работает по правилам Villagers Civ, а наше «послушание мобов» для него не применяется, чтобы поведение не дублировалось.

### 2. Рабы в нашей тюрьме

- Рабов и пленных Villagers Civ можно держать в клетках и зонах нашей тюрьмы.
- Наши пытки служат наказанием за побег и бунт, а слом снижает недовольство раба.

### 3. Реакция поселения

- Захват и пытки граждан поселения сообщаются Villagers Civ как преступления против него.
- Что дальше (недовольство, попытка освобождения стражей, война), решает Villagers Civ.

### 4. Тюрьмы жителей

- Владельцем нашей тюрьмы может быть поселение или государство Villagers Civ. Права надзирателей определяют их правила.
- Когда поселение арестовывает преступника, в том числе игрока, адаптер помещает его в тюрьму этого поселения.

## Что нужно от `api` Villagers Civ (предложение)

```java
// Кто такой житель с точки зрения цивилизации.
Optional<CitizenView> citizen(UUID entity);         // поселение, государство, статус (свободный, раб)

// Политические субъекты: владельцы тюрем.
Optional<PolityView> polity(String polityId);       // поселение или государство: id, тип, название
boolean canManagePrison(UUID player, String polityId);

// Рабство.
boolean enslave(UUID entity, Owner owner, Source source);  // source: CAPTIVE
void release(UUID entity);
void changeDiscontent(UUID entity, double delta);

// Преступления против поселения.
void reportCrime(UUID victim, UUID perpetrator, CrimeKind kind);  // CAPTURE, TORTURE, KILL

// События для подписки.
SlaveEscaped(UUID slave, String polityId)
SlaveRebelled(UUID slave, String polityId)
ArrestMade(UUID prisoner, String polityId)          // поселение задержало преступника
```

`Owner` описывает игрока или политический субъект. Подписка на события идёт через реестр слушателей в `api`.

## Технические условия

- В `mods.toml` нашего мода зависимость от `villagers_civ` необязательная (`mandatory=false`, `ordering="AFTER"`).
- Классы адаптера загружаются только после проверки, что мод установлен, иначе без Villagers Civ будет `NoClassDefFoundError`.
- Сборка: адаптер компилируется против артефакта `api` Villagers Civ (`compileOnly`). Их `api` написан на чистой Java 17 без зависимостей, группа `io.github.villagersciv`. Целевой способ: локальный Maven (`gradlew :api:publishToMavenLocal`). Публикацию они настроят, когда `api` станет стабильным. До этого исходники подключаются через `includeBuild`.
- Наши фичи и ядро про Villagers Civ не знают. Адаптер реализует точки расширения: владелец тюрьмы, источник пленных, реакция на захват и пытки.

## Статус согласования

- Сессия Villagers Civ приняла схему за основу. Точные имена появятся, когда они дойдут до рабства, суда и тюрьмы: это этапы после седьмого.
- Сейчас в их `api` есть только `land` (`LandGuard`, `LandRegistry`, `LandArea`) и `season` (`SeasonSource`).
- Реакцию на преступления решает Villagers Civ.
- Будет ли у Villagers Civ своя тюрьма или он воспользуется нашей, пользователь ещё не решил: это вопрос будущего обсуждения законов. Раньше здесь было записано, что своей тюрьмы у них не будет, но та сессия уточнила, что это было её предположение, а не решение пользователя.
- Приваты вроде Towny делят землю по чанкам. Если тюрьма или её зоны привязаны к такому привату, их граница может идти только по сетке чанков, а владельца тюрьмы определяем по чанку, а не по точным координатам блоков. Villagers Civ выравнивает так же границы участков и земли поселений.

## Порядок работ

1. Villagers Civ добавляет в `api` нужные интерфейсы, когда реализует рабство.
2. У нас появляются точки расширения в фичах плена и тюрьмы.
3. Адаптер связывает одно с другим.
