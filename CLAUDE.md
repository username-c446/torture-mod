# Torture Mod

Проект для Minecraft: мод для пыток над пленными игроками и мобами.
Текущая цель: Forge-мод на 1.20.1. В будущем: плагин на Paper API.

## Правила проекта

1. **Универсальность и портируемость.** Код пишем так, чтобы между API проекта и платформой можно было легко встроить прослойку и портировать проект на другую реализацию. Сейчас нужна реализация как Forge-мод на 1.20.1, в будущем нужна прослойка на Paper API (как плагин).
2. **Минимум зависимости от версии.** Код должен как можно меньше зависеть от фич внутри версий Minecraft, чтобы его было легко обновлять на новые версии.
3. **Только сервер.** Работаем преимущественно с уже существующим игровым поведением и стараемся не добавлять новых предметов и подобного: проект работает на стороне сервера и не должен быть обязательным к скачиванию на клиенте.
4. **Качество кода.** Код должен быть хорошо структурирован, оптимизирован и модулен, чтобы было легко менять и внедрять новые фичи.
5. **Потоки.** Состояние мира (сущности, блоки, инвентари) и состояние фич трогаем только на основном потоке сервера. Ввод-вывод (база, файлы, сеть) и тяжёлые вычисления над готовыми данными уходят в фон через `Scheduler.runAsync` / `supplyAsync`, а результат возвращается на основной поток. Основной поток не ждёт фоновую задачу (кроме однократной загрузки при запуске и сохранения при остановке), а фоновая задача никогда не ждёт основной поток — так дедлок невозможен.

## Рабочий процесс

- Функционал обсуждаем в форме дискуссии, вопросы пользователю задаём формой (AskUserQuestion).
- Каждую готовую фичу проверяем тремя способами: юнит-тесты логики на поддельной платформе, запуск сервера разработки (`gradlew :platform-forge-1.20.1:runServer`) и проверка вживую ботом на mineflayer.
